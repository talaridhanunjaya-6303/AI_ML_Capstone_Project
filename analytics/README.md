# Analytics Module

## Overview

This module performs Exploratory Data Analysis (EDA) and Machine Learning on the Titanic dataset.

## Files

* `01_eda.ipynb` – Data exploration and visualization
* `02_modeling.ipynb` – Data preprocessing, model training and evaluation
* `best_pipeline.pkl` – Saved best-performing ML pipeline
* `titanic.csv` – Dataset
* `requirements.txt` – Python dependencies

## Workflow

1. Load Titanic dataset
2. Perform data cleaning
3. Handle missing values
4. Encode categorical variables
5. Train multiple ML models
6. Evaluate model performance
7. Save the best model pipeline

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Jupyter Notebook

## Output

The trained machine learning pipeline is stored as:

```
best_pipeline.pkl
```
